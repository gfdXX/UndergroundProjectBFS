# Поиск маршрута в метро поиском в ширину

![Python](https://img.shields.io/badge/Python-3-3776AB?logo=python&logoColor=white)
![Jupyter](https://img.shields.io/badge/Jupyter-notebook-F37626?logo=jupyter&logoColor=white)

Учебный проект (МГТУ им. Н.Э. Баумана, 2023): программа спрашивает станции «откуда» и «куда», печатает маршрут между ними в виде цепочки `Станция -> Станция -> …` и примерное время в пути.

## Как устроено ([Underground_project.ipynb](Underground_project.ipynb))

- `Vertex` — станция: имя, соседи, веса перегонов, длина пути от старта;
- `InitSubway()` читает схему метро из файла `stations` и строит граф;
- `SetLength()` обходит граф в ширину от станции отправления и проставляет длины путей;
- `FindPath()` восстанавливает маршрут от конечной станции к начальной, `PrintPath()` печатает его;
- `Clean()` сбрасывает пометки перед следующим запросом.

Теория алгоритма — в [Algorithm_breadth_first_search_BFS.pdf](Algorithm_breadth_first_search_BFS.pdf).

## Как запустить

Нужен файл `stations` рядом с ноутбуком (в репозиторий он не попал). Формат — по одной ветке в строке (читаются первые 30 строк): названия станций, разделённые временем перегона в минутах:

```
Станция А--2--Станция Б--3--Станция В
```

Дальше выполните ячейки по порядку и вводите названия станций в ячейке «Запускать здесь». Пустой ввод завершает работу.
